# FAKE-NEWS-DETECTION-USING-ML
This project uses Machine Learning and Natural Language Processing to Classify news articles as Fake or Real
## Dataset

The datasets used in this project are stored in Google Drive because of their large file size.

### Download Datasets

- [Download Fake.csv](https://drive.google.com/file/d/1pUes6y1K057kCAJBBgP57oQfgLS5TF-K/view?usp=sharing)
- [Download True.csv](https://drive.google.com/file/d/19A8J6KUAvTdL63y0vTTloVzRZsECtpPw/view?usp=sharing)

### Dataset Description

- Fake.csv - Contains fake news articles.
- True.csv - Contains real news articles.
